# V3 Jarvis

Create a Power BI-style spreadsheet dashboard for Day Trader Portfolio Management, using the attached image(s) as the visual reference. Replicate the design quality, layout structure, charts, KPIs, colors, and overall user experience, but customize everything for day trading.

Requirements

 Fully responsive and mobile-first.

 All pages, dashboards, charts, tables, filters, and features must work perfectly on mobile and desktop.

 Modern, professional, premium Power BI-style design.

Include

 Portfolio Overview

 Daily, Weekly, Monthly, and Total P&L

 Equity Curve

 Win Rate

 Profit Factor

 Risk/Reward Ratio

 Drawdown

 Trade Journal

 Trade History

 Strategy Performance

 Asset Performance

 Session Analysis

 Risk Management

 Monthly Reports

Filters

 Date Range

 Asset

 Strategy

 Long/Short

 Trading Session

 Broker

 Account

Create dedicated pages for Dashboard, Trade Journal, Trade Entry, Analytics, Risk Management, Reports, and Settings.

The final result should feel like a premium Power BI dashboard adapted into a spreadsheet specifically for professional day traders.
